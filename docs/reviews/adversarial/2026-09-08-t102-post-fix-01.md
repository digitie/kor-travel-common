## 반복 no-go의 근본 원인

초기 구현은 alias 계약을 변수 이름 정규식과 일부 블록 문자열만으로 확인했다. CSS가 실제로 적용되는 선택자 범위, import 문법의 변형, Unicode identifier, 문자열·escape 경계를 하나의 입력 언어로 다루지 않아 검사기가 브라우저와 다른 의미를 승인했다. 경로 검사도 lexical 8.3 표기와 canonical 경로를 섞어 Windows에서 정상 fixture를 외부 경로로 오판했고, 진단은 상대 import와 식별자를 그대로 출력할 수 있었다. map과 weather의 `radius-md` 원천이 다른데 weather 값을 공용 shim에 덮어써 map 의미가 바뀌는 사실도 고정 원천 재확인 전에는 드러나지 않았다. 마지막으로 immutable raw evidence의 줄바꿈과 공백이 CI gate의 일부인데 이를 후보 artifact 정책과 함께 고정하지 않아 review 후보가 docs gate에서 실패했다.

수정은 이 문제들을 reviewer별 취향이 아닌 공통 계약으로 묶었다.

1. 지원하는 CSS 문법을 명시하고, escape는 문자열·identifier·`var()`·`@import` 위치를 포함해 fail closed 한다. 대소문자 `VAR`, 무세미콜론 선언, url/media/복수 import와 재귀 closure를 회귀 시험으로 고정했다.
2. alias 선언은 최상위 직접 `:root`, `.dark`, `:root, .dark`만 mode로 인정한다. 조건부 at-rule과 부모·후손 selector는 전체 stack을 확인해 거부하고, `both`는 root/dark 양쪽 identity로 중복 검사한다. Unicode custom property와 `var(--kt-…)` 이름도 검사한다.
3. lexical 경계와 canonical 경계를 분리해 비교하고 실제 Windows 8.3 경로·symlink·read failure를 같은 checker 계약에서 검증한다. 오류에는 입력 경로·식별자·값을 재출력하지 않는다.
4. 고정 map/weather 원천을 다시 대조해 공용 shim은 map `radius-md` control을 보존하고 weather 예제가 panel을 소유하도록 분리했다. weather dark shadow는 원천의 light 상속값을 유지하며 앱 고유 spacing은 비배포 예제에 남겼다.
5. reviewer 원본은 bytes와 SHA256을 보존하는 path별 attributes 예외로 고정하고, 후보 commit·tree·CI head를 서로 대체하지 않았다.
