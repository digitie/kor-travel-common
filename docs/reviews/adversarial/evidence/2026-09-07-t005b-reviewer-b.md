## B-P1-01 — Poetry 조건별 Git 선언 배열에서 branch 종류를 잃는다

- 위치: `tools/check_versions.py:1244`~`:1249`의 단일 dict 처리. list는 문자열로 바뀌고 Git 선언 추출에서 제외된다.

```toml

  {git="https://github.com/example/custom-lib.git", branch="v1.2.3", python=">=3.11,<3.12"},
  {git="https://github.com/example/custom-lib.git", tag="v2.0.0", python=">=3.12"},
```

- 권고: Poetry dependency와 group의 dict/list 항목을 모두 순회해 각 Git 선언 종류를 보존한다. 지원하지 않는 형태라면 입력 오류로 닫고 정상 lock ref로 대신하지 않는다. 단일/배열·조건별 branch/tag·복수 lock 항목을 함께 시험한다.

## B-P1-02 — `--requirement=파일`의 포함 내용을 조용히 버린다

- 권고: `--requirement 파일`과 `--requirement=파일`을 모두 경로로 정규화한다. 빈 경로·누락·순환은 기존 입력 오류로 유지하고 세 include 구문을 같은 BLOCKED 대조로 시험한다.
