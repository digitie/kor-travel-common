## A-P1-01 잔여: 일반 크기 텍스트의 대비를 3:1로 허용

- 위치: `docs/standards/design-tokens.md:113`(메타·캡션 3:1), 같은 파일 `:120`(tint 위 상태 텍스트 3:1), `docs/tasks/T-103-kt-contrast-ux-lint.md:21`, `docs/architecture/style-delivery.md:98`.

- T-103 목표는 WCAG 대비 검사이며, TK-8은 tertiary의 용도를 메타·캡션, status의 용도를 상태 **텍스트**로 명시한다. large text 또는 non-text로 제한하지 않는다. [W3C WCAG 2.2 SC 1.4.3 해설](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)의 일반 텍스트 기준은 4.5:1이고 3:1은 큰 텍스트에 적용된다. 캡션·상태라는 역할 자체는 예외가 아니다(2026-09-08 공식 문서 확인).
- 영향: 후속 에이전트가 T-103을 문서대로 구현하면 새로 추가된 일반 크기 캡션·상태 라벨의 대비 미달을 정상으로 처리한다. 문서 사이 숫자를 낮은 값으로 맞추는 것만으로 최초 지적의 잘못된 gate를 닫을 수 없다.
