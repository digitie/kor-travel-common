## 근거·정상 대조

[YAML 1.2.2 공식 규격](https://yaml.org/spec/1.2.2/)의 block indentation·일반/인용 scalar·flow collection 규칙과 [GitHub workflow 문법](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax)의 step/with map 정의를 2026-09-07에 확인했다. PyYAML 대조는 구문 유효성만 확인했으며 GitHub workflow 실행 성공의 증거로 사용하지 않았다.

[actions/setup-node 공식 문서](https://github.com/actions/setup-node)의 정적 version/파일 입력 관계도 확인했다. candidate의 명시된 제한에 따라 숫자·list·matrix·파일 참조를 NO_ENGINES로 남긴 것은 이 리뷰에서 오탐으로 취급하지 않았다. 정적 낮은 Node는 BELOW_FLOOR·exit 1, 정적 정상 문자열은 OK·exit 0, 동적/파일/list/숫자는 NO_ENGINES·exit 1로 양 OS 결과가 같았다.

duplicate key·flow mapping·tag·document marker·block scalar·uses+run 동시 입력은 일반 오류 2로 정상 거부됐다. 기존 npm/Python의 168개 전체 회귀는 통과했다.
