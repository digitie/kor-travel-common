# UI 패키지 외부 코드 고지

공용 UI는 GPL-3.0-or-later로 제공하며 shadcn/ui Radix 레지스트리에서 가져온 MIT 컴포넌트를 포함한다. MIT 저작권과 전문은 SHADCN_LICENSE에 보존한다. 각 소스의 Origin/Modified와 루트 shadcn-sources.json에 URL·원문 SHA256을 기록한다. 설치 의존성은 각 배포물의 고지도 적용된다.

VirtualTable의 Map 원천 커밋과 경로는 소스 Derived-From 및 PROVENANCE.md를 따른다. 지도 엔진·provider 코드는 포함하지 않는다.
