# 공통 Toast

웹에서 알림이 필요한 앱만 사용하는 선택형 패키지다. `import { Toast } from "@kor-travel/toast"`로 Radix UI1.8.1의 동일한 Toast namespace를 가져온다. Provider/Root/Title/Description/Close/Viewport, duration·pause·focus·swipe·접근성 동작은 Radix 원본이 담당한다. 자체 타이머나 알림 상태 엔진은 추가하지 않는다.

기존 C11 UI0.2.0/tokens0.1.1 산출물은 변경하지 않는다. 새0.1.0 tgz의 정확 bytes/SRI를 현재 중앙 원장과 소비 앱 lock에서 검증한다. 모바일 프로필에는 설치하지 않는다.
