# 에이전트 설정 파일 출처 고지

이 파일은 설정 6개와 함께 전달하는 고지다. JSON은 주석을 허용하지 않으므로 파일별 SPDX 고지를 대신한다. 소비 저장소에서는 이 파일을 `docs/notices/kor-travel-common-agent-config.md`에 둔다. common의 `templates/README.md`에 있는 동반 파일 복사 절차를 함께 수행한다.

- SPDX-License-Identifier: GPL-3.0-only
- SPDX-FileCopyrightText: 2026 Youn-sok Choi (digitie)
- 적용 파일: `antigravity.json`, `claude.json`, `.mcp.json`, `opencode.json`, `.codex/config.toml`, `.gemini/mcp.json`. 실제 채택한 파일과 common 원래 파일명의 대응은 동반 출처 기록에 보존한다.
- 원천 저장소·고정 커밋·원천 경로·수정 요약: `docs/provenance/kor-travel-common-agent-config.md`의 PV-007~012 중 채택한 파일의 행을 확인한다. 이 사본은 common의 `PROVENANCE.md`에서 가져오며 common을 다시 받아야만 읽을 수 있는 상대 링크로 대체하지 않는다.
- 라이선스 전문과 원천 고지: `LICENSES/kor-travel-geo-LICENSE.txt`를 함께 보존한다. `.codex/config.toml`의 헤더도 지우지 않는다.

O-20 권리자 재선언 evidence가 없으므로 `-or-later`로 바꾸지 않는다. 소비자에서 설정을 수정하면 동반 출처 기록에 수정 날짜와 요약을 추가하며 원천 기록은 유지한다.
