# 에이전트 설정 파일 출처 고지

이 디렉터리의 설정 6개는 [PROVENANCE PV-007~012](../../PROVENANCE.md)에 기록한 geo 원천을 따른다. JSON은 주석을 허용하지 않으므로 이 파일이 파일별 고지를 대신한다. 설정을 소비 저장소로 복사할 때 이 고지와 [geo 원문 사본](../../LICENSES/upstream/kor-travel-geo-LICENSE.txt)을 함께 보존한다.

- `codex.config.toml`은 파일 헤더에도 고지가 있다. `antigravity.json`·`claude.json`·`mcp.json`은 원본과 정규화 JSON이 같다. `opencode.json`은 instructions 추가와 키 정렬, `gemini.mcp.json`은 antigravity 원본에서 filesystem을 제거했다(Modified: 2026-09-07 확인).

O-20 권리자 재선언 evidence가 없으므로 `-or-later`로 바꾸지 않는다. 설정 채택 절차는 [템플릿 색인](../README.md)과 [에이전트 규약](../../docs/standards/agent-conventions.md)을 따른다.
